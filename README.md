# OUAGx Agent — Terminal Edition

Local AI computer and authorized-network agent controlled from the terminal.

Features: terminal chat, Ollama/OpenAI-compatible AI, SQLite memory, filesystem tools, system information, controlled shell, authorized network diagnostics, permission levels, confirmations and audit logs.

Windows quick start: double-click START_OUAGX.bat.

Manual start: create a Python virtual environment, install requirements.txt, copy .env.example to .env, then run python -m ouagx_agent.
